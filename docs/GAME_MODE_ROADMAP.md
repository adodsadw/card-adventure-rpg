# 星界遠征後續遊戲模式規劃

## 第一優先：非同步競技場（推薦 v1.8）

玩家設定一組防守隊伍，其他玩家挑戰由伺服器模擬的防守隊伍，不需要雙方同時在線。

建議功能：

- 每日 5 次免費挑戰。
- 勝利增加積分，失敗小幅扣分。
- 青銅、白銀、黃金、星耀等段位。
- 每週結算鑽石、金幣與競技幣。
- 戰鬥紀錄與復仇功能。
- 伺服器產生 Battle Seed，降低前端竄改風險。

這種模式比即時 PvP 穩定、成本低，也較適合 Cloudflare Workers + D1。

## 第二優先：無盡星塔

- 關卡會逐層變強。
- 每週重置部分進度。
- 特定樓層提供 Boss 與特殊規則。
- 增加英雄培養、裝備與隊伍搭配的長期目標。

## 第三優先：每日 Roguelike 裂縫

- 每次進入隨機產生路線與增益。
- 戰鬥後三選一 Buff。
- 當次挑戰失敗後重置。
- 每日更換種子，所有玩家面對相同挑戰。

## 第四優先：公會 Boss／公會戰

- 全公會共同攻擊大型 Boss。
- 依個人傷害與公會總傷害發獎。
- 公會戰可先採非同步據點攻防，避免即時連線複雜度。

## 第五優先：好友切磋與隊伍分享

- 使用邀請碼分享防守隊伍。
- 好友挑戰不消耗正式競技次數。
- 分享戰報或隊伍組合。

## 不建議第一時間做即時 PvP

真正即時 PvP 需要持續連線、配對、斷線重連、延遲補償與更強的防作弊機制。現階段建議先完成「非同步競技場」，確定玩家願意長期遊玩後，再評估 Durable Objects 或 WebSocket 即時對戰。
